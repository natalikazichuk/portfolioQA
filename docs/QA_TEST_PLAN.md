# QA NK — Test Plan

## Scope
Functional, UI, responsive, cross-browser, accessibility, performance, navigation, forms and content.

## Test types
- Functional testing
- Exploratory testing
- UI/UX testing
- Responsive testing
- Cross-browser testing
- Accessibility checks
- Basic performance checks
- Link validation
- Form validation

## Browsers
Chrome, Firefox, Edge, Safari where available.

## Devices
Desktop, tablet and mobile widths.

## Entry criteria
Build is available and core routes render without blocking errors.

## Exit criteria
No open Critical/High defects; core journeys pass; responsive layout is acceptable; broken links are resolved.
