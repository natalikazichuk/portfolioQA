# QA NK — Project Overview

## Goal
Create a memorable QA portfolio that demonstrates testing ability rather than only listing skills.

## Target audience
- QA recruiters
- QA Team Leads
- Engineering managers
- Clients looking for manual/API QA support

## Product principle
The portfolio itself is treated as a product and must have its own test plan, test cases, bug reports and release summary.

## Core experience
1. Landing page
2. Bug Hunt mission
3. QA Quest project map
4. Case studies
5. Bug Museum
6. QA Lab
7. AI Response Lab
8. Recruiter Mode
9. CV / GitHub / contact
